Virtual Mouse & Keyboard

A computer vision based human-computer interaction system that enables mouse and keyboard control using hand gestures.

View GitHub Explore Project

Project Features

🖱 Virtual Mouse

Control mouse movement using hand and finger gestures detected through the webcam.

⌨ Virtual Keyboard

Select and interact with virtual keyboard keys using hand gestures and finger positioning.

✋ Hand Tracking

MediaPipe hand landmarks are used to identify finger positions and gestures in real time.

📷 Webcam Based

The system uses a standard webcam as the primary input device without requiring physical peripherals.
